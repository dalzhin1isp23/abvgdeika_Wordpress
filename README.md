# Abvgdeika WordPress

Учебный проект, связанный с разработкой и настройкой сайта на WordPress.

Репозиторий содержит PHP-скрипт для автоматизации создания и настройки страниц сайта.

## Основной функционал

* автоматизация настройки WordPress;
* создание или настройка страниц сайта;
* использование PHP и WordPress API;
* упрощение первоначальной конфигурации проекта.

## Структура

```text
abvgdeika_Wordpress/
├── abvgdeyka-pages-setup.php
├── README.md
└── .gitignore
```

## Использование

Скрипт предназначен для использования внутри WordPress-проекта.

Перед запуском необходимо:

1. Развернуть WordPress.
2. Добавить скрипт в структуру проекта.
3. Настроить параметры в соответствии со структурой сайта.
4. Выполнить скрипт в среде WordPress.
